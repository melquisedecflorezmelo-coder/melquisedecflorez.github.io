# Portafolio web — Melquisedec Florez Melo

Archivos:
- index.html — página principal
- CV_MELQUISEDEC_FLOREZ_MELO.pdf — hoja de vida enlazada al botón de descarga

Para publicarlo gratis con HTTPS:
1. Crear una cuenta en GitHub.
2. Crear un repositorio público llamado `melquisedecflorez.github.io` (el nombre debe coincidir con el usuario de GitHub).
3. Subir `index.html` y `CV_MELQUISEDEC_FLOREZ_MELO.pdf`.
4. En Settings → Pages, seleccionar Deploy from a branch → `main` → `/root`.
5. GitHub generará una dirección HTTPS del tipo `https://melquisedecflorez.github.io/`.
